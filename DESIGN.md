# Design System

## Stack
- framework: Vue 3 + Vite (route components are lazy-loaded, except the home page)
- styling: design system in `frontend/src/design/` (tokens, base, primitives, components, motion, fx — see its README); the old `frontend/src/styles.css` lives in `@layer legacy` and only shapes screens that were not redesigned
- components: Vue single-file components with scoped styles; shared UI in `frontend/src/ui/`, app shell in `frontend/src/shell/`
- animation: anime.js 4 (reveals, split headings, counters, SVG drawing), Motion for Vue (`motion-v`, shared-layout pills), OGL (WebGL ambient background), CSS transitions
- icons: lucide-vue-next
- fonts: Unbounded (display), Onest (body), JetBrains Mono (data) from Google Fonts

## Tokens
- redesign tokens: `--bm-*` brand and signal colours (`--bm-blue: #1652d8` is the original BMRL blue and must not change), `--c-*` surfaces, lines and text, `--r-*` radii, `--ease-*` / `--dur-*` motion; the legacy names below are bridged to them
- brand: `--primary`, `--primary-strong`, `--accent`
- backgrounds: `--bg`, `--panel`, `--panel-muted`
- logo preview: `--logo-preview-dark`
- text: `--text`, `--muted`
- shape: `--card-radius`, `--control-radius`
- shadow: `--shadow`
- themes: `:root` and `:root[data-theme='dark']`
